# fablake documentation

`fablake` is a filesystem-first Python library for Microsoft Fabric OneLake
Lakehouse access.

It focuses on a small, explicit API:

- `Lakehouse` to bind a workspace and lakehouse context
- `LakehousePath` to work with paths under `Files`
- `LakehouseTable` locators for paths under `Tables`

Project repository: [github.com/billybillysss/fablake](https://github.com/billybillysss/fablake)
